# Python Bootcamp 🚀

Este repositorio contiene los ejercicios y proyectos desarrollados durante el curso **["The Complete Python Bootcamp From Zero to Hero in Python"](https://www.udemy.com/course/complete-python-bootcamp/)** (Udemy).  
El objetivo es dominar Python desde cero hasta un nivel profesional, aplicando buenas prácticas en programación, automatización y creación de aplicaciones.

---

## 🧠 Temas cubiertos

Aunque todavía estoy en proceso, el curso incluye una amplia variedad de temas que voy trabajando progresivamente:

- Instalación de Python, entorno de desarrollo y línea de comandos.  
- Estructuras de datos básicas: cadenas (strings), listas, diccionarios, tuplas, conjuntos.  
- Control de flujo: condicionales, bucles (for, while), comprensión de listas.  
- Funciones, parámetros, valores de retorno, alcance de variables (scope).  
- Programación orientada a objetos (POO): clases, herencia, polimorfismo.  
- Módulos, paquetes, manejo de errores/excepciones, pruebas unitarias (unit tests).  
- Automatización y tareas reales: manipulación de archivos (PDF, Excel), web‑scraping, GUIs básicas.  

---

## ⚙️ Tecnologías utilizadas

- **Python** (versión 3.x)  
- Entornos, editores y terminales apropiados para desarrollo multiplataforma  
- Módulos y librerías estándar de Python (y aprendiendo algunos externos conforme avanzo)  
- Buenas prácticas de código: POO, tests, modularidad, legibilidad
